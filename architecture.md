# Архитектура приложения Simon Says

## Назначение
Проект представляет собой веб-игру «Simon Says» на память. Приложение разделено на два независимых пакета (монорепозиторий): библиотеку переиспользуемых UI-компонентов и основное веб-приложение с клиентским роутингом.

## Состав проектов

### 1. Библиотека `ui-library`
Назначение: хранение независимых UI-компонентов для отрисовки игрового интерфейса.
Структура:
- `src/SignalPanel` — панель с 4 цветными кнопками (красная, зелёная, синяя, жёлтая). Принимает пропсы для подсветки (`activeColor`), блокировки (`disabled`) и колбэк клика (`onColorClick`).
- `src/ProgressIndicator` — индикатор прогресса. Принимает пропсы `level` (текущий уровень), `sequenceLength` (длина) и `record` (рекорд).

### 2. Приложение `frontend`
Назначение: демонстрация работы игры с использованием библиотеки `ui-library`. Здесь реализована игровая логика и маршрутизация.
Структура:
- `src/pages/HomePage.tsx` — стартовая страница с приветствием и кнопками перехода в игру и статистику.
- `src/pages/GamePage.tsx` — экран самой игры, управляющий состоянием последовательности и таймерами.
- `src/pages/StatsPage.tsx` — страница с таблицей результатов (сохраняются в `localStorage`).
- `src/App.tsx` — корневой компонент с настройкой маршрутов React Router.
- `src/game/types.ts` — типы данных для игры.
- `src/game/physics.ts` — модуль расчета таймингов.

## Игровая логика и взаимодействие
Игра использует конечный автомат (FSM) со состояниями: `idle` (ожидание), `playing` (демонстрация и ввод) и `gameover` (проигрыш).
В текущей версии игровой цикл реализован через хуки React (`useEffect` и `setInterval`) для показа цветов. В дальнейшем планируется переход на `requestAnimationFrame`, если потребуется физика отскоков.

## Маршрутизация (React Router v7)
Приложение использует клиентский роутинг на базе `react-router-dom`.
- `/` — `HomePage` (Главное меню)
- `/game` — `GamePage` (Игровой процесс)
- `/stats` — `StatsPage` (Таблица рекордов)
Защищённые маршруты не предусмотрены, так как игра не требует авторизации.

## Используемые библиотеки и версии
- React (v19.3.1) — компонентный интерфейс.
- TypeScript (v5.9.3) — строгая типизация (запрет `any`).
- Vite (v7.3.7) — сборщик проекта.
- Jest (v30.5.2) + React Testing Library (v19.3.1) — тестирование.
- ESLint (v9.39.5) — линтинг.

## Компоненты
- `SignalPanel`: пропсы `activeColor`, `disabled`, `onColorClick`.
- `ProgressIndicator`: пропсы `level`, `sequenceLength`, `record`.

## Использование библиотеки
Основное приложение `frontend` подключает библиотеку через зависимость `"@my-app/ui-library": "file:../ui-library"`. Компоненты импортируются по имени пакета. Стили библиотеки подключаются в `main.tsx`.
