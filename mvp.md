# Требования к MVP (Минимально жизнеспособный продукт)

## Описание
MVP — браузерная игра «Simon Says» на память. Игрок должен запоминать и повторять визуальную последовательность цветов. Приложение работает локально в браузере и не требует сервера. 

## Use case: Сыграть в игру
**Актор:** Игрок.
**Предусловия:** Приложение открыто в браузере, игрок находится на главном экране.

**Основной сценарий:**
1. Игрок нажимает кнопку «Начать играть» (переход на страницу `/game`).
2. Игрок нажимает кнопку «Начать игру» на игровом экране.
3. Система генерирует случайную последовательность, начиная с 1 цвета.
4. Система по очереди подсвечивает кнопки на панели `SignalPanel`.
5. Игрок повторяет последовательность, кликая по кнопкам.
6. Если игрок нажимает правильно — система увеличивает длину последовательности на 1 и переходит на новый уровень.
7. Игра продолжается до первой ошибки игрока.

**Альтернативный сценарий (Ошибка):**
- Если игрок нажимает неверную кнопку, система завершает игру, показывает текущий рекорд и сохраняет результат (дату и счет) в `localStorage` для истории.
- Игрок может перейти на страницу `/stats` и посмотреть таблицу своих прошлых результатов.

**Результат:** Игрок потренировал память, обновил свой рекорд, результат сохранен в историю.

## Входит в MVP
- Главная страница с навигацией.
- Игровой экран с панелью кнопок (`SignalPanel`).
- Индикатор прогресса (`ProgressIndicator`).
- Подсветка кнопок с задержкой (анимация).
- Проверка правильности кликов и повышение уровня.
- Страница статистики с сохранением результатов игр в локальное хранилище.
- Клиентский роутинг (`react-router-dom`).

## Не входит в MVP (на следующие итерации)
- Звуковое сопровождение (Web Audio API). Интеграция четырех коротких аудиофайлов (mp3), привязанных к соответствующим кнопкам (`onColorClick`), для улучшения пользовательского опыта.
- Расширенный UX/UI. Добавление CSS-анимаций (например, эффекта переворота карточек), счетчика комбо-очков и более плавных переходов между экранами.
- Гибкая настройка сложности. В текущей версии длина последовательности увеличивается линейно (1, 2, 3...). В будущем планируется добавить режимы «Легкий», «Средний» и «Сложный» с разной скоростью показа и стартовой длиной.
